جایگزینی تصویر شاخص ۷ شهرستان استان البرز با تصاویر شب‌نمای وب‌پی همراه افزونه — فقط تصویر عوض می‌شود؛ متن نوشته‌ها دست نمی‌خورد.

== Description ==

این افزونه تصویر شاخص صفحات ۷ شهرستان استان البرز را در نوع نوشته‌ی «شهر» با نسخه‌های جدید شب‌نما جایگزین می‌کند:

* کرج (کلان‌شهر دامنهٔ البرز)، فردیس، ساوجبلاغ (درهٔ کردان و هشتگرد)، نظرآباد (تپهٔ باستانی ازبکی)، چهارباغ، اشتهارد، طالقان (سد طالقان)
* سبک تصاویر: عکس واقع‌گرایانهٔ هوایی شبانه از مکان مشهور هر شهرستان با چراغ‌های روشن + عنوان فارسی + زیرنویس + واترمارک SARZAMIN ARYAN
* مشخصات فایل‌ها: WEBP، ۱۶۰۰×۹۰۰ (۱۶:۹)، هر فایل ≤ ۳۰۰ کیلوبایت
* متن جایگزین (ALT) توصیفی فارسی برای هر تصویر همراه بسته است
* شناسه‌ی sha1 روی پیوست ذخیره می‌شود تا اجرای دوباره، فایل تکراری بارگذاری نکند
* پیدا کردن صفحه با اسلاگ‌های جایگزین (مثلاً ferdows/fardis، sojablogh/savojbolagh، talqan/taleqan)

نکته‌های مهم:

* فقط تصویر شاخص جایگزین می‌شود؛ متن، متا و وضعیت انتشار نوشته‌ها تغییر نمی‌کند.
* تصویر قبلی از کتابخانه‌ی رسانه حذف نمی‌شود؛ تنها از حالت «تصویر شاخص» خارج می‌شود.
* قالب فرزند «سرزمین آریان» باید فعال باشد (نوع نوشته‌ی «شهر»).

== Installation ==

1. zip را از «افزونه‌ها → افزودن → بارگذاری» نصب و فعال کنید.
2. به «ابزارها → تصویر شاخص البرز» بروید، شهرستان‌ها را انتخاب و دکمه‌ی جایگزینی را بزنید.
3. با WP-CLI: «wp sa-county-featured-alborz» (یا با «--slugs=karaj,talqan» برای انتخاب موردی)

== Frequently Asked Questions ==

= آیا متن صفحات تغییر می‌کند؟ =
خیر. فقط تصویر شاخص صفحه جایگزین می‌شود.

= اگر دوباره اجرا کنم چه می‌شود؟ =
اگر همان تصویر قبلاً تنظیم شده باشد (sha1 یکسان)، بدون بارگذاری مجدد رد می‌شود.
