درون‌ریز ۲۹ شهرستان استان خوزستان همراه تصاویر شاخص WEBP؛ همهٔ نوشته‌ها به‌صورت پیش‌نویس وارد می‌شوند.

== Description ==

این افزونه بستهٔ شهرستان‌های خوزستان را در نوع نوشتهٔ «شهر» وارد می‌کند:

* متن کامل مقاله، جدول‌ها، FAQ، منابع و داده‌های سئو
* فیلدهای مدل داده، مختصات، نقشه، فصل سفر و ارتباط با برگهٔ استان
* تصویر شاخص WEBP هر شهرستان در اندازهٔ ۱۲۰۰×۶۰۰
* ALT هر تصویر شامل نام همان شهرستان است
* همهٔ تصاویر و مقاله‌ها با وضعیت DRAFT ONLY وارد می‌شوند و چیزی منتشر نمی‌شود.

== Installation ==

1. پوشهٔ «sa-city-importer-khuzestan» را در «wp-content/plugins/» قرار دهید یا فایل ZIP را بارگذاری کنید.
2. افزونه را فعال کنید.
3. از منوی «درون‌ریزی شهرستان‌ها» شهرستان‌های خوزستان را انتخاب کنید.
4. با WP-CLI: «wp sa-city-import khuzestan»

== Frequently Asked Questions ==

= آیا نوشته‌ها منتشر می‌شوند؟ =
خیر. همهٔ نوشته‌ها به‌صورت پیش‌نویس وارد می‌شوند.

= تصویر شاخص چگونه وارد می‌شود؟ =
فایل WEBP هر شهرستان از پوشهٔ assets/counties به رسانه منتقل می‌شود و ALT توصیفی شامل نام همان شهرستان روی پیوست ثبت می‌گردد.
