جایگزینی تصویر شاخص ۲۶ شهرستان استان سیستان و بلوچستان با تصاویر هوایی روز (زاویهٔ ۴۵ درجه) همراه افزونه — فقط تصویر عوض می‌شود؛ متن نوشته‌ها دست نمی‌خورد.

== Description ==

این افزونه تصویر شاخص صفحات ۲۶ شهرستان استان سیستان و بلوچستان را در نوع نوشته‌ی «شهر» با نسخه‌های جدید جایگزین می‌کند:

* زاهدان (مسجد مکی)، چابهار (کوه‌های مریخی)، ایرانشهر (قلعهٔ ناصری)، سراوان، سرباز (درهٔ گاندو)، خاش (دامنهٔ تفتان)، زابل (شهر سوخته)، نیک‌شهر، کنارک (خلیج پزم)، سیب و سوران (قلعهٔ سیب)، زهک، مهرستان، دلگان، هیرمند، قصرقند، فنوج، نیمروز (آسبادها)، میرجاوه، هامون (کوه خواجه)، تفتان (قلهٔ آتشفشانی)، بمپور (قلعهٔ کهن)، راسک، دشتیاری (رود باهوکلات)، لاشار (اسپکه)، گلشن (گشت سراوان)، زرآباد
* سبک تصاویر: عکس واقع‌گرایانهٔ هوایی روز با زاویهٔ ۴۵ درجه، سازه یا منطقهٔ طبیعی معروف هر شهرستان در مرکز کادر، رنگ‌های زنده و سینمایی + عنوان فارسی + زیرنویس + واترمارک SARZAMIN ARYAN
* مشخصات فایل‌ها: WEBP، ۱۶۰۰×۹۰۰ (۱۶:۹)، هر فایل ≤ ۳۰۰ کیلوبایت
* متن جایگزین (ALT) توصیفی فارسی برای هر تصویر همراه بسته است
* شناسه‌ی sha1 روی پیوست ذخیره می‌شود تا اجرای دوباره، فایل تکراری بارگذاری نکند
* پیدا کردن صفحه با اسلاگ‌های جایگزین (مثلاً nik-shahr/nikshahr، dalgan/dalagan، qasr-e-qand/qasr-e-ghand، sib-va-suran/sib-and-suran، bampur/bampour)

نکته‌های مهم:

* فقط تصویر شاخص جایگزین می‌شود؛ متن، متا و وضعیت انتشار نوشته‌ها تغییر نمی‌کند.
* تصویر قبلی از کتابخانه‌ی رسانه حذف نمی‌شود؛ تنها از حالت «تصویر شاخص» خارج می‌شود.
* قالب فرزند «سرزمین آریان» باید فعال باشد (نوع نوشته‌ی «شهر»).

== Installation ==

1. zip را از «افزونه‌ها → افزودن → بارگذاری» نصب و فعال کنید.
2. به «ابزارها → تصویر شاخص سیستان» بروید، شهرستان‌ها را انتخاب و دکمه‌ی جایگزینی را بزنید.
3. با WP-CLI: «wp sa-county-featured-sistan» (یا با «--slugs=zahedan,chabahar» برای انتخاب موردی)

== Frequently Asked Questions ==

= آیا متن صفحات تغییر می‌کند؟ =
خیر. فقط تصویر شاخص صفحه جایگزین می‌شود.

= اگر دوباره اجرا کنم چه می‌شود؟ =
اگر همان تصویر قبلاً تنظیم شده باشد (sha1 یکسان)، بدون بارگذاری مجدد رد می‌شود.
