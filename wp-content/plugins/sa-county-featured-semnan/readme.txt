جایگزینی تصویر شاخص ۸ شهرستان استان سمنان با تصاویر شب‌نمای وب‌پی همراه افزونه — فقط تصویر عوض می‌شود؛ متن نوشته‌ها دست نمی‌خورد.

== Description ==

این افزونه تصویر شاخص صفحات ۸ شهرستان استان سمنان را در نوع نوشته‌ی «شهر» با نسخه‌های جدید شب‌نما جایگزین می‌کند:

* سمنان (دروازهٔ ارگ)، شاهرود (بسطام و جنگل ابر)، دامغان (مسجد تاریخانه)، گرمسار (دروازهٔ کویر مرکزی)، مهدی‌شهر (شهمیرزاد)، سرخه، میامی (دشت کالپوش)، آرادان (کاروانسرای ده‌نمک)
* سبک تصاویر: عکس واقع‌گرایانهٔ هوایی شبانه از مکان مشهور هر شهرستان با چراغ‌های روشن + عنوان فارسی + زیرنویس + واترمارک SARZAMIN ARYAN
* مشخصات فایل‌ها: WEBP، ۱۶۰۰×۹۰۰ (۱۶:۹)، هر فایل ≤ ۳۰۰ کیلوبایت
* متن جایگزین (ALT) توصیفی فارسی برای هر تصویر همراه بسته است
* شناسه‌ی sha1 روی پیوست ذخیره می‌شود تا اجرای دوباره، فایل تکراری بارگذاری نکند
* پیدا کردن صفحه با اسلاگ‌های جایگزین (مثلاً semnan-city/semnan، shahrud/shahroud، mehdishahr/mahdishahr، sorkheh/sorkhe، meyami/mayamey)

نکته‌های مهم:

* فقط تصویر شاخص جایگزین می‌شود؛ متن، متا و وضعیت انتشار نوشته‌ها تغییر نمی‌کند.
* تصویر قبلی از کتابخانه‌ی رسانه حذف نمی‌شود؛ تنها از حالت «تصویر شاخص» خارج می‌شود.
* قالب فرزند «سرزمین آریان» باید فعال باشد (نوع نوشته‌ی «شهر»).

== Installation ==

1. zip را از «افزونه‌ها → افزودن → بارگذاری» نصب و فعال کنید.
2. به «ابزارها → تصویر شاخص سمنان» بروید، شهرستان‌ها را انتخاب و دکمه‌ی جایگزینی را بزنید.
3. با WP-CLI: «wp sa-county-featured-semnan» (یا با «--slugs=damghan,garmsar» برای انتخاب موردی)

== Frequently Asked Questions ==

= آیا متن صفحات تغییر می‌کند؟ =
خیر. فقط تصویر شاخص صفحه جایگزین می‌شود.

= اگر دوباره اجرا کنم چه می‌شود؟ =
اگر همان تصویر قبلاً تنظیم شده باشد (sha1 یکسان)، بدون بارگذاری مجدد رد می‌شود.
